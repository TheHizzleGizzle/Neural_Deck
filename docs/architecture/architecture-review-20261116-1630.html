03

Three problems

Each is traced to file and line, and each maps to a deepening move in section 04.

P1

Late AI replies land in whichever deck is open — and the loading bar goes dark early

Corrupts dataextends earlier finding
  • Every callback reads activeSession when the reply arrives, not when you tapped.
  • A branch reply for a card in Deck A, arriving while Deck B is open: indexOf(parent) is −1, so the children are appended to Deck B, where their parent doesn't exist. They render as root cards and get saved.
  • Nothing blocks a second tap. Requests queue on one thread; the first reply turns the loading bar off while the second is still running.
